## Required matrix evidence

A real row may be promoted only when provider metadata supplies device ID, manufacturer, model, Android version/SDK, RAM, ABI, screen/resolution/DPI, and the run returns test output, timestamp, exact APK SHA, logs, screenshots, video where supported, and crash/ANR evidence. Unsupported provider/device combinations are recorded as `BLOCKED_BY_PLATFORM`; absent catalog entries are `NOT_TESTED`, not omitted.

## Layer separation

General compatibility covers install, launch, permissions, navigation, Profiles, Security Center, Compatibility Center, restart, and state persistence. Network runtime covers Wi-Fi/4G/5G, IPv4/IPv6, dual stack, DNS, switching, airplane mode, connection loss, and recovery. VPN/TUN/Tor covers consent, packet routing, DNS leaks, bootstrap, circuits, `.onion`, Kill Switch, service death, and background behavior. A general UI or instrumentation result never implies a PASS for the network layers.
